# Element of Ink — repository instructions

## Purpose and scope
Creative tattoo-portfolio website and visual asset workflow. The current README is a minimal preview note; inspect the actual tracked source before making claims about deployment or completeness. Known files include `mask-editor.html`, `css/premium.css`, `js/premium-layout.js`, `js/contact-banner.js`, and `scripts/refine_tattoo_masks.py`.

## Content and asset constraints
- Preserve rights and attribution for tattoo photography, client images, artist names, and branding.
- Do not invent artist credits, availability, testimonials, contact information, or pricing.
- Treat client-identifying photos, submissions, and photo metadata as sensitive until publication rights are established.
- Keep image treatments reversible; do not overwrite original assets or masks without backups.
- Protect accessibility, mobile layout, and legibility across visual updates.

## Development and validation
Check the actual HTML/CSS/JS and mask-generation scripts before editing them. Avoid assuming a build system that is not present. For visual changes, run a local preview and inspect desktop/mobile rendering; for Python image processing, verify inputs, outputs, and sample QA assets. Describe skipped checks explicitly and do not claim publication or deployment without confirmation.
